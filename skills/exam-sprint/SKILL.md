# 考前速成整理（exam-sprint）

目标不是读懂全书，是**会做题并通过考试**。用 sprint 工具做管道，你负责内容判断与写作。

## 先问清楚（缺一条就别开工）
1. 科目、教材（作者/版次）、考哪几章
2. 老师口径：知识点还是课后题？有无划重点、题型、允许带什么
3. 资料路径：书 PDF、PPT、作业、网课截图/目录
4. 考试时间
5. 只自用，还是要整理成能公开的

## 流程（S0–S6）
- **S0 摸底**：project.init → scan.pdf（可按 --ranges 传章节页段）→ scan.ppt → scan.shots。记下 PDF 页与书页的偏移，写 outline.md。
- **S1 知识网络**：一条主线 + 每环核心量与代表公式，做成表格。先写这个，再写细节。
- **S2 逐项释义**：每个概念五段——定义 → 公式 → 每一项是什么 → 为什么长这样 → 考场怎么用；每章末尾【易错清单】。
- **S3 例题归范**：每类题写题眼（题干出现什么字）→ 动作（立刻写什么）→ 为什么 → 坑。来源里的数字必须独立验算，错了要标出来并给正确值。
- **S4 A4 底稿**：按 S2 章序压缩，符号统一；template.install 拿模板，双栏排版，两页填满约 95%。
- **S5 题目集**：作业题与书后题全做，答案三位有效数字，每题一句考点；完整解答单独一份。
- **S6 查漏**：对照 checklist.md 逐条打勾，缺的补进讲义和底稿；网课与教材符号不同先出符号总表。

## 每次出 PDF 之后必做
1. render.tex 看 pdf 是否生成、errors 是否为空——**别看退出码**，本机常假报 127。
2. render.preview 出图，逐页用眼睛看：表格有没有冲出页边、标题有没有粘在正文里、希腊字母有没有消失、有没有空白页。
3. check.accept 过一遍（日志 0 错、产物非空、页数达标）。
4. 交付件按 <科目>_<序号>_<名称>.pdf 放到项目根目录，中间件留在 _work。

## 硬规矩
- 交付 PDF 优先；作图题直接给图，不要丢代码让用户自己跑。
- 不要公式速查卡——要概念网络 + 逐项释义 + 解法归范。
- 每个符号都说清含义、单位、取值范围。
- 来源数字要验算；发现来源（网课/PPT/答案）算错，指名并给正确值。
- 中文排版里希腊字母一律进数学模式，否则 \small 里会直接消失。
